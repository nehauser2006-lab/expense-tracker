# Ledger — Expense Tracker

A simple, single-page expense tracker built to log daily spending, 
categorize it, and visualize where your money goes — all directly 
in the browser, no backend required.

🔗 **Live demo:** [Add your GitHub Pages link here]

## Features
- Add expenses with title, amount, category, and date
- Delete entries you no longer need
- View total spent, entry count, and this month's spending at a glance
- See a category-wise spending breakdown with a custom bar chart
- Fully responsive — works on mobile and desktop
- Data is saved locally using the browser's localStorage, so your entries persist between visits

## Built with
- HTML
- CSS (custom design, no frameworks)
- Vanilla JavaScript (no external libraries)

## How to use
1. Open the [live link](#) above
2. Fill in the form to add an expense
3. View your totals and category breakdown update automatically
4. Click the × next to any entry to delete it

## Why no backend?
This project was intentionally built frontend-only so it can be opened 
instantly via a single link, with no server setup required. A Flask + 
SQLite backend version was also built during development as a learning 
exercise in full-stack development.
